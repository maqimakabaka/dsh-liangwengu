# dsh-LiangWenGu · 梁文谷

> DSH 谷价调度器：把「写好的指令」放到 DeepSeek 谷价时段自动发送，省下峰时那部分 token 费用。

入口在 DSH 左侧边栏（图标 + 「梁文谷」），面板分四个标签页：**新建会话 / 历史会话 / 记账本 / 设置**。

## 功能

### 谷价队列

- 写好一段指令，选择模型、推理等级（reasoningEffort）、权限预设、附件后加入队列。
- 触发方式默认是「谷价开始后 10 秒执行」（避开计价切换的那一分钟），也可以指定具体时间。
- 目标可以是**新建会话**（可设标题、工作目录、模型、权限、附件），也可以是**已有的历史会话**（追加发送）。
- 峰时到点的任务默认顺延到下一个谷价窗口；可在设置里改成「立即发送」。
- 失败自动重试一次，仍失败则标记为失败并保留原因。

### 峰谷时段

- 内置官方规则：UTC 01:00–04:00、06:00–10:00（北京时间 09:00–12:00、14:00–18:00）为峰时，仅周一至周五；其余时间（含周末与法定节假日）为谷价，谷价 = 峰价 × 0.5。
- 可从官方定价页自动抓取刷新（启动时 / 每天 / 每周 / 手动），失败时沿用缓存与内置参考价。
- 中国法定节假日由插件自动抓取（PowerShell 请求 `chinese-days` 数据，jsdelivr 与 unpkg 并行回退），全天按谷价计费；每年 12 月 15 日之后启动会补抓次年数据，失败时在面板提示「节假日抓取失败」。
- 面板顶部用小标签显示当前是「谷」还是「峰」，配倒计时与「今日已用」估算金额。

### 余额提醒

- 同时支持两种身份：配置了 `DEEPSEEK_API_KEY` 的环境用 API key 查询；只用 DSH 账号登录的用户自动回退到账号余额（充值钱包 + 赠金钱包合计）。
- 低于阈值时暂停队列、记录告警并播放「余额告警」提示音；已发送的指令不受影响，用户确认后恢复队列。
- 每轮对话结束后自动刷新一次余额，面板顶部的余额与「今日已用」随之更新；手动点「刷新」会按结果显示「刷新成功」或「刷新出错：原因」。
- 余额查询失败不会阻塞调度（fail-open），只在面板与日志里提示。

### 记账本

- 监听会话用量事件，按官方峰谷单价估算每个助手中的 token 花费。
- 展示「本机累计 / 今日 / 累计 tokens / 记录轮次」与「近 7 天使用记录」。
- **仅为估算**：按官方人民币单价（元 / 百万 tokens）与 token 用量计算，未计入账号折扣、赠送额度抵扣、Search/Fetch 调用与缓存命中差异，实际账单请以 DeepSeek 官方为准。

### 设置

- 显示模式：浅色 / 深色 / 跟随 DSH。
- 语言 / Language：中文 / English / 跟随 DSH，切换即时生效。
- 调度总开关、峰时策略、峰谷定价抓取、余额闸门与频率、三路提示音（余额告警 / 谷价提醒 / 峰价提醒，可各自换文件与调音量）、显示模式、运行日志。

## 安装

插件以 DSH bundle 的形式安装到某个 profile：

```bash
# 本地目录安装（开发时最方便）
dsh plugin --profile <profile> add link:C:/Users/96596/dsh-liangwengu

# 或者从 Git 仓库安装
dsh plugin --profile <profile> add github:maqimakabaka/dsh-LiangWenGu
```

桌面端读取 `desktop` profile，安装后需要重启 DSH 才会加载插件。

## 数据与隐私

- 插件数据保存在 `~/.dsh/liangwengu/`：`state.json`（配置、队列、定价缓存、余额、记账）、`pricing.last.md`（最近一次抓取的官方定价页）、`uploads/`（面板上传的附件）。
- 附件只支持图片与文本类文件：面板上传时会过滤，宿主侧再用扩展名 / MIME 白名单兜一层，其它类型直接拒绝。
- 面板与宿主之间走同源 HTTP 路由 `/dsh-liangwengu/*`，带 Host / Origin / `Sec-Fetch-Site` 校验；所有网络请求只发往 DeepSeek 官方接口。
- 写接口都会校验输入：配置项按白名单收敛（非法值丢弃并在响应 `warnings` 里说明）、任务入队前检查指令/会话/时间/预设，未知任务返回 404，非法 JSON 请求体返回 400。
- `state.json` 损坏或来自旧版本时会自动归一化重建，不会阻塞插件启动。

## 说明

- 定价与峰谷时段以 DeepSeek 官方为准；官方调整后点一次「立即抓取」即可。
- 记账本是估算值，仅供日常参考。
- 提示音：插件内置三路默认音效 `assets/YuE.mp3`（余额告警）、`assets/Gu.mp3`（谷价提醒）、`assets/BuGu.mp3`（峰价提醒），随包分发、不引用外部路径。设置页每行都有 ▶ 播放、文件夹图标（导入自定义，导入后复制到 `~/.dsh/liangwengu/sound-<kind>-*`）、「恢复默认」和音量数字块（0–100）。
- 记账本为估算：按官方人民币单价（元 / 百万 tokens）与 token 用量计算，未计入账号折扣、赠送额度、Search/Fetch 调用与缓存命中差异。

## 界面

- 入口在 DSH 左侧边栏；主面板四个标签页，视觉对齐 DSH Web UI 设计规范（`--dsw-*` 令牌、六级圆角、32px 控件高度、22px 主输入卡）。
- 权限选择使用官方盾牌菜单：仅可查看 / 工作区内修改 / 完全权限 / 自动审查（EXP，需在 DSH 中开启实验功能）。
- 每次切换标签页都会保留正在编辑的草稿（存于 localStorage）。
